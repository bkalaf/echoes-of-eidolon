# Echoes of Eidolon 0.3.0

## Added

### Companion and occupation authoring
Audience: OPERATORS
Routes: /admin/campaign/planner, /admin/data/occupations

Administration can author the twelve-companion roster, ordered occupation attributes, world assignments, skills, and Transformation progression through shared domain owners.

### World economy and party status
Audience: PLAYERS
Routes: /game

The game workspace adds world-specific purse, inventory, withdrawal history, Bank interactions, recovery condition, and Inn meeting surfaces without imposing a fixed inventory capacity.

### Managed settlement soundtracks
Audience: BOTH
Routes: /account/settings, /admin/atlas, /game

Administrators can assign 80 deterministically reconciled city and tavern soundtrack sources to settlements, while players share synchronized mute, master, soundtrack, and narrative volume settings across Account and the game bottom bar.

### Gameplay and World Atlas
Audience: PLAYERS
Routes: /gameplay, /gameplay/world-atlas

Public Gameplay and World Atlas pages explain the playable experience and provide an explorable public atlas without disclosing player state.

### Governed bulk changes
Audience: OPERATORS
Routes: /admin/bulk-changes, /api/external/bulk

An ordered, typed review queue supports bounded external data changes with dry-run validation, explicit administrative decisions, inactivity expiry, and append-only audit evidence.

### WorldBuilding v3 simple authoring
Audience: OPERATORS
Routes: /admin/data

Species, Culture, Breed, and Character authoring now uses scalar presentation text, recursive taxonomy, controlled Breed ecology and group classifications, canonical personality expressions, and fail-closed research staging. The retired SpeciesGroup and structured appearance persistence paths are no longer available.

### Witness Puzzle Box prototype lab
Audience: OPERATORS
Routes: /admin/puzzles/test-lab, /admin/puzzles/:puzzleBlueprintId/test

The checksum-pinned 70-Blueprint Witness Puzzle Box bank can be verified and imported transactionally into stable Blueprint roots, immutable generator versions, and two ordered Bobalus hint templates. An administrator-only lab provides a working interactive sample and server-side answer check for every Blueprint across all five difficulty tiers and nine method families without creating assignments or starting the live challenge timer.

## Changed

### Character subtype identity
Audience: OPERATORS
Routes: /admin/data, /admin/campaign/planner

Witnesses, Architects, and Companions now use their underlying Character identity directly, so subtype administration and campaign references no longer maintain competing identifiers for the same individual.

### Reachability is a release gate
Audience: BOTH
Routes: /

Every active application screen or state must have an authorized UI entry, an intentional exit, and browser-level reachability evidence before this release can publish.

### Deployment verifies the migrated application
Audience: OPERATORS
Routes: /api/health, /api/version

Production promotion now takes its guarded backup and applies migrations before running PostgreSQL integration and browser verification, so database-dependent release checks exercise the schema that will actually serve the candidate build. Build identity reports the deployed package version independently from the latest published release-note index.

## Fixed

### Import-ready WorldBuilding and companion forms
Audience: OPERATORS
Routes: /admin/data, /admin/campaign/planner, /admin/data/occupations, /admin/atlas

All 34 registered Data entities now resolve every editable field to a typed form control with required/type/list validation and an explicit workflow reason for persisted fields excluded from generic editing. WorldBuilding previews reject canonical identity and presentation drift before apply, canonical names remain paired with immutable persistence IDs, PET-only null fields cannot be authored accidentally, and five-part clothing uses structured controls. Dependency-closed envelopes preserve whole canonical components and persisted references, while authored and inherited presentation require independent static and semantic completion audits. Companion skill participation may remain unassigned, Occupation, Transformation, and settlement soundtrack forms reliably load existing state, and bulk-envelope detail exposes its ordered review actions.

Breed authoring now records the required Human, Beast, Mythos, or Pet population classification independently from biological Species classification, allowing Beast and Pet populations to share one canonical animal Species without leaking sapient presentation into Pet output.

Breed hierarchy now supports one optional canonical parent, with parent-first import ordering and enforced same-Species, same-population, and acyclic relationships for nationality roots and other coverage groupings.

Canonical WorldBuilding packages can now be imported transactionally from explicit, checksum-verified archives. Supplied persistence IDs are preserved exactly, Culture remains an independent root, registry taxonomy may retain authoritative skipped ranks, and intentionally reviewed null personality assignments remain valid.

Concrete Witness transformation now preserves the source Architect's Soul across two distinct Character records. The 54 department seats use SPONSORSHIP and INNOVATION in place of the retired presiding-role values, while Hans and Noell remain departmentless original Architects outside the ordinary Witness path.

The complete owner-authored Architect and Witness identity set can now be reconciled transactionally and rerun without duplicate rows. Witness definitions use explicit WDF identities, three-color percentage records, and source-Architect Soul links. The Overseer, Herald, and Steward Guide links remain static canonical mappings to existing Characters and Souls rather than database Guide rows. Mother is represented as the explicitly authorized non-biological Character and Soul underlying The Steward; ordinary biological and worldbuilding Characters still require a Breed across supported write paths.

Production promotion now rebuilds the exact server artifact after browser teardown, verifies that artifact before restart, and creates migration backups with owner-only permissions.

### Reliable Bulk API modes and campaign documents
Audience: OPERATORS
Routes: /admin/data/bulk-operations, /admin/operations, /admin/campaigns/:campaignId/documents, /admin/campaigns/:campaignId/document-quests

Keyed and keyless Bulk API sessions now satisfy the database contract used by the administration controls. The dead global Document Builder selector has been removed, and Operations directs document corpus and research-planning work to the campaign-owned surfaces. Its pending persistence-removal migration refuses to drop any superseded Document tables when even one row exists, preserving the complete preexisting data graph for owner review.
